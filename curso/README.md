# Lógica de Programação

Técnico em Desenvolvimento de Sistemas · Grau Técnico · 20 aulas de 3 horas

Do algoritmo em português ao JavaScript no navegador, construindo ao longo da disciplina um sistema de **Reserva de Laboratórios**.

- Projeto da disciplina: [`../projeto/`](../projeto/README.md)
- Como entregar (branch, Pull Request, checkpoints): [`../README.md`](../README.md)

Cada aula tem a explicação com exemplos, exercícios em aula, o desafio para a próxima aula e o resumo.

## Checkpoints do projeto

| CP | Aula | Entrega |
|---|---|---|
| CP1 | 3 | Sua pasta `alunos/<sua-pasta>/`, README com o algoritmo, fluxograma, `dados/laboratorios.csv` e `dados/cursos.csv` |
| CP2 | 6 | Portugol: menu validado, laboratórios em vetores, matriz dia × turno com conflito e capacidade |
| CP3 | 10 | JS: menu validado + CRUD de cursos em funções |
| CP4 | 11 | Objetos, CRUD de turmas e professores, reserva com conflito e capacidade, lista de espera e desfazer |
| CP5 | 12 | Calendário (matriz), buscas, Map e Set, ordenações — regra de negócio pronta |
| CP6 | 16 | Microprojetos M0 a M9 prontos (um `.js` por seção de tela), cada um com commit |
| CP7 | 18 | `app/` integrado (3 telas), GitHub Pages, README final e apresentação |

Cada checkpoint é entregue por um **Pull Request** da sua branch para a `main`.

Atividades do plano oficial: **Atividade 01** (lista de exercícios) = desafios de cada aula · **Atividade 02** (desenvolvimento de algoritmo) = checkpoints do projeto.
